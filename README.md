# Student Attendance Management System using ShaktiDB

## Project Overview
This project is a database-based Student Attendance Management System developed using ShaktiDB. It is designed to manage student information, subjects, and attendance records efficiently. The project demonstrates fundamental database operations and SQL concepts while generating meaningful attendance reports.

## Objectives
- Manage student records
- Manage subject details
- Record student attendance
- Generate attendance reports
- Calculate attendance percentage

## Features
- Student Management (Add, View, Update, Delete)
- Subject Management
- Attendance Management
- Student-wise Attendance Reportcat README.md
- Subject-wise Attendance Report
- Attendance Percentage Report
- Present vs Absent Summary

## Technologies Used
- ShaktiDB 17.10
- SQL
- Ubuntu 24.04 LTS
- Oracle VirtualBox
- GitHub

## Database Tables
1. Students
2. Subjects
3. Attendance
