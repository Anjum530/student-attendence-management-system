# Student Attendance Management System using ShaktiDB

## 1. Introduction
The Student Attendance Management System is a database application developed using ShaktiDB. It helps manage student information, subjects, and attendance records efficiently. The project demonstrates SQL operations and database management concepts.

## 2. Objectives
- Store student details
- Manage subject information
- Record daily attendance
- Generate attendance reports
- Calculate attendance percentage

## 3. Modules

### Student Management
- Add Student
- View Student
- Update Student
- Delete Student

### Subject Management
- Add Subject
- View Subject
- Update Subject
- Delete Subject

### Attendance Management
- Mark Attendance
- View Attendance Records

### Reports
- Student-wise Attendance Report
- Subject-wise Attendance Report
- Attendance Percentage Report
- Present vs Absent Summary

## 4. Database Tables

### Students
- student_id
- name
- department
- semester

### Subjects
- subject_id
- subject_name
- subject_code

### Attendance
- attendance_id
- student_id
- subject_id
- attendance_date
- status

## 5. Technologies Used
- ShaktiDB 17.10
- SQL
- Ubuntu 24.04 LTS
- Oracle VirtualBox
- GitHub

## 6. Conclusion
This project demonstrates how ShaktiDB can be used to build a simple and efficient attendance management system. It showcases database design, SQL operations, and report generation in a structured way.
